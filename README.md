# mence.dev

Welcome to my interactive portfolio. This project was developed to simulate a real Linux terminal.

## Features

- **Simulated Terminal:** Full CLI-style interface.
- **Integrated Game:** Includes a *shoot 'em up* minigame called `starship`.
- **Portfolio:** Information about my career, technology stack, and projects.

## Available Commands

Upon opening the terminal, you can use the following commands:

- `help`: Lists all available commands.
- `ls`, `cd`, `cat`, `mkdir`, `rm`: Basic file management commands.
- `whoami`: Profile information.
- `resume`: Displays my resume.
- `neofetch`: System statistics.
- `starship`: Launches the minigame (use arrows to move/shoot and ESC to quit).
- `theme <name>`: Changes the theme (monokai, green, light, purple, blue).
- `clear`: Clears the terminal.
